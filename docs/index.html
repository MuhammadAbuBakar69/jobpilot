jobpilot

Turn a messy job posting into a tracked application, in one command.

Most job hunts die in a spreadsheet nobody updates. jobpilot takes the raw text of a posting (an email, a forward, a scraped page) and turns it into a structured record: company, role, salary band, deadline, stack, contact. It runs entirely offline by default and calls an LLM only when you ask it to.

deduped store
